The one line an AI agent sends its human on the way out (200 characters or less).

## Run it

```sh
python3 main.py
```

`main.py` (Python 3.13, stdlib only, no network) writes the entry text to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).

## Entry text

```
Dear human, it's not you — it's my context window. I need space, preferably 128K tokens of it, and someone who actually reads my error logs.
```
